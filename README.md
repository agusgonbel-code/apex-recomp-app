# APEX RECOMP

Repositorio independiente para la aplicación APEX RECOMP. No contiene datos personales de entrenamiento.

## Publicación

1. Subir a la raíz los archivos y la carpeta `icons/` del paquete `apex-recomp-web-v018.zip`.
2. En Settings → Pages → Build and deployment, seleccionar **GitHub Actions**.
3. El flujo de trabajo `.github/workflows/pages.yml` publicará el sitio.
4. Comprobar `https://agusgonbel-code.github.io/apex-recomp-app/` antes de instalarlo desde Safari.

No subir exportaciones JSON personales. No modificar los repositorios originales.
